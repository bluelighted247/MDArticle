## 🚀 ZeroBuild

Deploy 10,000 pages in 0.01s. No Git, no DB. Just enter one Cloudflare API key, type your markdown, and click "Publish" to get lifetime free hosting.

## ⚡ Why ZeroBuild?
* **O(1) Deployment:** Never wait for full rebuilds. It only updates the new page and a tiny `index.json`.
* **Zero Git Overhead:** No GitHub or terminal required. Completely user-friendly for non-programmers.
* **Instant Provisioning:** Auto-configures Cloudflare Pages (Direct Upload API) out of the box.

## 🛠 Tech Stack
* **App:** Tauri (Rust + HTML/CSS) — Ultra-lightweight desktop app.
* **Hosting:** Cloudflare Workers (100% Free)
